# Security Policy

## Supported versions

Only the latest release on `main` (currently 3.x) receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/iamsomraj/SHARE-IT-social-media-application/security/advisories/new),
or email **iamsomraj@gmail.com** with:

- a description of the issue and its impact,
- steps to reproduce or a proof of concept,
- affected endpoints, files or versions.

You can expect an acknowledgement within a few days. Once a fix is available,
the advisory will credit you unless you prefer otherwise.

## Known advisories

Known advisories in build-time dependencies that have no upstream fix are
tracked in the [changelog](./CHANGELOG.md#known-advisories).
